# Feliz cumpleaños, Kimberly — Angular

Página de cumpleaños interactiva creada con Angular standalone components. Incluye globos, regalos simbólicos, un ramo de girasoles animado y una carta sorpresa.

## Ejecutar localmente

```bash
npm install
npm start
```

Después abre `http://localhost:4200`.

## Compilar para producción

```bash
npm run build
```

El resultado se genera en `dist/cumple-kimberly`.
